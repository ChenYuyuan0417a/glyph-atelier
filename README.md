# 字形工坊 · Glyph Atelier

纯本地运行的字体改造工作台。双击 `index.html` 即可用，不需要服务器、不需要联网、不依赖任何 CDN。

- A 字体：默认系统自带的 `PingFang.ttc`，首次导入后自动记住（IndexedDB），下次打开直接带着。
- B 字体：任意 `.ttf / .otf / .ttc`，用来给 A 供字形。
- 导出：严格保留原文件的字体名称、字重、字面信息与表结构，只改字符本身。

## 第一次打开

1. 首次运行会弹出引导，点「选择 A 字体」并把 `PingFang.ttc` 拖进去（或直接点选）。
2. 之后每次打开都会自动载入上次的 A 字体，不用再导入。

## 替换字符：三条路，任选

**一、写字符（最快）**

在左栏「写字符」框里写要换的字，可以一次写很多个，如 `永和九年岁在癸丑`。停手 0.3 秒后自动选中这些字，并显示「A 有 N · B 有 M」——A 里没有的字会被标出来。然后点「换选中字」或到右侧面板调样式。

> 这个框不是生成文字，它只负责把「你写出来的字」自动圈进选区，省掉一个个点。

**二、手动多选和区间连选**

- 长按某格 0.4 秒：这一格成为锚点，同时进入多选。
- 再点任意一格：自动选中锚点到这一格之间的全部字符（含首尾），网格上一条连续的选区就出来了。再点别的格，仍从原锚点连过去。
- `Shift + 点`：以当前锚点连选，点完把终点变成新锚点，适合一段一段接。
- `Ctrl / ⌘ + 点`：把那一格从选区里剔掉。
- `全选全部`：整个字面全部字符（PingFang 为 30,987 个，不再截断）。
- `全选结果`：当前筛选或搜索出来的那一批。
- `清空`：清掉选区，同时解除锚点。

字符多也不靠硬扛：DOM 里始终只有可视的那几十格（虚拟列表），滚到哪儿就把哪几行塞进去，划出屏幕的直接扔掉；滚动条是靠一层占位高度撑出来的。三万多个字符实测 DOM 只有 50 来个格子，全选也不掉帧。

**三、整批灌入（不选字）**

左栏顺序是 A 字体 → B 字体 → 写字符，B 卡片就在 A 下面，不用往下翻找。三个按钮：

| 按钮 | 作用 |
| --- | --- |
| 换选中字 | 只处理当前选区 |
| 换全部重合 | 只处理 A、B 都有的字符 |
| 换全部字符 | B 的所有字符整批落到 A（新增的也会补进 A） |

下方 `复制字形 / 替换宽度` 决定落地方式：复制＝字形取 B、宽度用 A 的并重新居中；替换＝字形和宽度都按 B 来。

PingFang 全量灌 30,987 字大约 15 秒，期间有进度提示，中途不要切标签页。

## 改字符属性

右栏「字体属性」，上面一幅预览，跟着你当前看的标签走：在 A 标签里看的是改动后的字形，在 B 标签里看的是 B 原来的字形。没选字符时画「永和九年」做样张。

- 没有「应用」按钮：拖一下滑杆、点一下色板、或在右边数字框里直接填数，整面所有字符立刻生效，预览同一步跟上。
- 可调：字体大小、粗细、字形间距、浓淡、上浮下沉、行距（写进 `hhea.lineGap`，影响整个字体）。每个滑杆右边都有数字输入框，边敲边生效，不用回车。
- 粗细按轮廓外法线向外扩、负值向内收；浓淡小于 100 时按比例收细笔画，不是只改预览透明度。
- 整面样式按字形编号烘焙，不依赖 cmap：TTC 里 232 个字面、以及没被 cmap 映射的替换字形都会一起变。
- `字形居中`：按字宽把轮廓摆到水平正中，开了就是所有字符一起居中。
- 颜色：七个预设 + 取色器。颜色写进 `COLR/CPAL` 色层，支持彩色的软件能显示；iOS 系统字体本身不显示彩色字形，整面染色还会让导出体积明显变大。
- 改错了按 `撤销上一步`，滑杆、数字框、颜色、居中开关都会跟着回退到那一步的状态。

## 手机端

手机打开也按电脑端三栏排：viewport 固定 1180，整页等比缩到屏幕宽度，左边合集、中间字形、右边属性都在原位，不再拆成上下堆叠的单栏。窄到放不下时保底最小宽度 1180，横向可拖，不改排布。要看清小字双指放大即可。

## 一键成品（PingFang.ttc 作底）

左栏「修改字面合集」下面有 `PingFang.ttc 一键换字 · 出成品`：

1. A 已就位就直接点；没载入过会先让你选一次 `PingFang.ttc`（浏览器读不了硬盘路径，之后自动记住）。
2. 没有 B 就自动弹文件选择，选完立刻开始，不用再点第二次。
3. 系统先清空 A 的全部字符（含样式、颜色），再把 B 的全部字符按 A 的字宽整批复制进去。
4. 完事直接进导出弹窗，文件名与格式照旧：`PingFang.ttc` 还是 `PingFang.ttc`，232 个字面、name 表、字重一个字节不动。

## TTC 合集

PingFang.ttc 里塞了 232 个字面（UI Text / SC / Watch …），它们共用同一套 `glyf/loca/hmtx` 轮廓表——改一个字面等于改全部。左栏会自动显示 `共享轮廓` 或 `各自独立`。

- `B 全部 → 合集复制 / 替换`：一次把 B 的全部字符落到合集里所有字面。
- `清空合集所有字面的字符`：把 232 个字面一起清空（可撤销）。
- 共享轮廓的合集导出时打包成 `.ttc`，逐字面保留各自的 name 与字重。

## 导出

点右上「导出 A 字体」，可以选：

- `整包 .ttc`：多字面合集的完整打包，别人装进去还是 232 个字面。
- `TrueType .ttf`：只导出当前编辑的那一个字面。

导出进度条走完会自动下载到系统下载目录，文件名沿用 A 的原文件名与扩展名。

## 更换 A 字体

点「更换 A 字体」会先弹窗确认：

> 原 A 字体系统已经被设计为 PingFang.ttc 字体文件，你确认要换掉 A 字体的文件吗？

- 确认 → 选择新文件，A 字体被替换。
- 取消 → 继续用当前的 PingFang.ttc，什么也不动。

## 保留原则（代码层面）

- `name` 表、`OS/2` 表、`GSUB/GDEF` 等布局表原样搬运，一个字节不改。
- 未触碰的字符按原始字节复制；只有被改的字符才重新编码轮廓与 `hmtx` 宽度。
- `head.checkSumAdjustment`、各表 checksum 重新计算，导出的包能被 fontTools / 系统正常加载。
- 一个字面都没有独立轮廓表时（各自的 `glyf` 不同），合集导出会明确报错而不是偷偷拼出一个坏包。

## 文件结构

```
index.html          页面
css/style.css       样式
js/font-engine.js   字体引擎（TTC/TTF/OTF 解析、轮廓变换、表重建、TTC 打包）
js/app.js           界面与状态
tools/              开发期自检脚本（Node + fontTools 校验、截图预览），交付使用不需要
```

## 备注

- 全部计算在浏览器内存里做，不落任何临时文件到磁盘。A 字体存 IndexedDB（约 37 MB）。
- 换过 `js/*` 后记得把 `index.html` 里 `app.js?v=` 的版本号 +1，否则 `file://` 会读缓存。
- 极端大字体（上百万字符）全量灌入会吃内存，属预期，分批操作更稳。
